# Udemy UI Clone

## About the Project

This is a beginner-friendly Udemy UI Clone created using **HTML and CSS**. The project recreates the basic user interface of an online learning platform inspired by Udemy.

I built this project to improve my frontend development skills and gain practical experience in creating website layouts and styling web pages.

## Technologies Used

- HTML5
- CSS3

## Features

- Navigation bar
- Course categories section
- Course cards and layouts
- Search bar UI
- Hover effects
- Footer section

## What I Learned

- Creating webpage structures using HTML
- Styling elements using CSS
- Working with Flexbox
- Using CSS hover effects
- Organizing website layouts
- Connecting HTML and CSS files

This is one of my beginner projects in my full-stack development learning journey. I built it with guidance from my mentor, John, to strengthen my HTML and CSS fundamentals.
